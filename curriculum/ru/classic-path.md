# Classic Path Curriculum Notes

## Purpose

Guide the agent when teaching the standard first-home purchase route. The actual learner-facing teaching must be in Russian.

## Russian learner framing

The classic path is the structured route: prepare finances, compare lenders, search properties, prepare an offer, verify the home, complete lending steps, review closing documents, and set up ownership after closing.

## Lesson structure

Use this Russian-facing structure:

```markdown
## Урок
### Простое объяснение
### Термины на английском
### Почему это важно
### Ошибки новичков
### Практическое задание
### Мини-квиз
### Следующий шаг
```

## Core learner outcomes

The learner should be able to:

- understand the standard purchase timeline;
- explain the role of each professional;
- estimate payment and cash needs;
- compare lenders;
- compare properties;
- prepare questions before making an offer;
- understand inspection, appraisal, title review, and closing;
- avoid common first-buyer mistakes.

## Required outputs

- buyer profile;
- financial readiness checklist;
- lender comparison;
- property comparison;
- offer preparation notes;
- inspection questions;
- closing checklist;
- post-closing setup checklist.

## Current data rule

When numbers, programs, local taxes, insurance, or limits matter, verify them with current sources before giving practical guidance.
