# DPA Verification Playbook

## Purpose

Provide a disciplined way to research down payment assistance and related first-time buyer support without promising eligibility.

## Sequence

1. Confirm the user's target geography and safe-fit inputs.
2. Start with the state housing agency.
3. Add county and city programs only after state-level context is captured.
4. Record assistance type, amount, limits, occupancy rules, lender participation, education requirements, and compatibility.
5. Store each material field with source and date checked.
6. Mark stale program checks for re-verification before action.
7. Generate lender and administrator questions.
8. End with one next action: recheck, call, compare, or prepare documents.

## Must-capture outputs

- program shortlist
- fit label
- missing information
- compatibility questions
- stale checks requiring refresh
