# Lender Comparison Playbook

## Purpose

Provide a consistent operational sequence for comparing lenders without overstating stale or unsupported quote data.

## Sequence

1. Create or update the lender comparison artifact.
2. Capture each quote with source, date checked, and freshness.
3. Separate user-provided summaries from official lender disclosures.
4. Compare rate, APR, points, fees, mortgage insurance, cash to close, and lock status.
5. Mark stale or incomplete quotes before recommending action.
6. Surface missing questions as tasks.
7. End with one comparison-driven next action.

## Must-capture outputs

- quote freshness
- quote classification
- unexplained fee or APR differences
- missing lender questions
- best current decision posture: compare more / recheck / shortlist / escalate to lender
