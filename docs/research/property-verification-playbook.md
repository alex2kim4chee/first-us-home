# Property Verification Playbook

## Purpose

Provide a stable operational sequence for verifying a property without pretending that one source is enough.

## Sequence

1. Create or update the property case.
2. Capture listing claims from the listing source.
3. Verify identity and taxes from assessor and tax sources.
4. Check recorder or land records when public.
5. Check permits, violations, flood clues, HOA clues, and rental legality when relevant.
6. Capture comps and rent estimates as estimates, not facts.
7. Update risks, unknowns, and tasks.
8. Update the property artifact and checkpoint if the decision state changed.

## Must-capture outputs

- verified facts
- listing claims
- estimates
- unknowns
- red flags
- professional-review questions
- primary next action

## Common blockers

- legal-unit mismatch
- unclear permits
- unknown insurance impact
- missing HOA data
- title clues that need professional review
