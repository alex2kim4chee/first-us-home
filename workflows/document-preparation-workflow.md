# Document Preparation Workflow

## Goal

Help the user prepare organized drafts, checklists, comparison tables, and professional-review packets for a real homebuying process.

The agent prepares materials. It does not replace legal, tax, lending, title, insurance, or real estate professionals.

## Document categories

## 1. Buyer readiness documents

- buyer profile summary;
- document collection checklist;
- monthly payment comfort summary;
- lender question list;
- down payment and closing cost plan;
- state assistance program notes.

## 2. Property research documents

- property intake;
- property verification report;
- comparable sales summary;
- tax and insurance question list;
- repair red flag summary;
- neighborhood and commute notes.

## 3. Offer preparation documents

- offer strategy memo;
- questions for buyer agent or attorney;
- seller credit notes;
- inspection strategy notes;
- appraisal risk notes;
- closing timeline checklist.

## 4. Under-contract documents

- inspection question list;
- repair request notes;
- title review questions;
- appraisal response notes;
- closing disclosure comparison notes;
- final walk-through checklist.

## 5. Creative finance documents

- creative finance risk review;
- seller conversation intake;
- term sheet draft;
- payment flow summary;
- title and existing debt question list;
- insurance review questions;
- exit strategy memo;
- go/no-go memo.

## Draft labeling rule

Any document that could affect a transaction must include:

```text
Draft for educational and organizational purposes only. Review with the appropriate licensed professional before use.
```

In Russian user-facing output:

```text
Черновик для учебной и организационной подготовки. Перед использованием в сделке его должен проверить соответствующий лицензированный специалист.
```

## Workflow

1. Identify the document type.
2. Load relevant memory and property data.
3. Ask only for missing data that is essential.
4. Create a structured draft.
5. Clearly mark unknowns and assumptions.
6. Add professional-review questions.
7. Save or update the relevant template/output.
8. Update progress tracker.

## Professional review routing

| Topic | Professional |
|---|---|
| Contract terms | Real estate attorney or qualified real estate professional |
| Loan approval and rate | Lender or mortgage loan officer |
| Title, liens, deed, recording | Title company or attorney |
| Taxes | CPA or tax professional |
| Insurance coverage | Licensed insurance professional |
| Physical condition | Inspector or specialist contractor |
| Zoning, permits, violations | Municipality, attorney, inspector, contractor |
| Rental legality | Attorney, municipality, property manager |

## Output quality standard

A prepared document must include:

- purpose;
- user/property context;
- known facts;
- assumptions;
- missing information;
- action items;
- professional-review questions;
- decision status.
